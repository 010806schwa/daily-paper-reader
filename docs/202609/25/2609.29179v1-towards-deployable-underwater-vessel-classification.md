## 摘要
我们提出了一种紧凑的水下声学分类框架，结合了多表示特征工程、时间统计池化，以及面向声学时频表示和耳蜗表示设计的紧凑卷积架构。我们研究了多种传统表示和受听觉启发的表示，并首先在 ShipsEar 数据集上评估了轻量级分类器和卷积神经网络（CNN）。在所提供的划分上，一个两层 CNN 取得了 0.9918 的宏平均 F1，而径向基函数支持向量机（RBF-SVM）达到了 0.9883。然而，源录音出处无法重构，导致无法验证独立于录音的泛化能力。因此，我们在 DeepShip 数据集上采用分割之前进行录音级划分的方式进行评估。在该协议下，一个具有 157K 参数的紧凑 CNN 取得了 0.7226 的测试宏平均 F1，而一个具有 11.17M 参数的 ResNet18 在匹配设置下并未提升验证性能。这些结果表明，表示感知的特征与模型设计，以及严格的录音级评估，对于紧凑型水下声学系统的分类性能和可部署性至关重要。

## Abstract
We propose a compact underwater acoustic classification framework combining multi-representation feature engineering, temporal statistical pooling, and compact convolutional architectures designed for acoustic time-frequency and cochlear representations. We investigate multiple conventional and auditory-inspired representations and first evaluate lightweight classifiers and Conventional Neural Networks (CNNs) on ShipsEar dataset. On the provided split, a two-layer CNN achieves a macro F1 of 0.9918, while a Radial Basis Function Support Vector Machine (RBF-SVM) reaches 0.9883. However, source-recording provenance cannot be reconstructed, preventing verification of recording-independent generalisation. We therefore evaluate on DeepShip dataset using recording-level partitioning before segmentation. Under this protocol, a 157K-parameter compact CNN achieves a test macro F1 of 0.7226, while an 11.17M-parameter ResNet18 provides no improvement in validation performance under the matched setting. These results demonstrate the importance of representation-aware feature and model design, together with rigorous recording-level evaluation, for classification performance and deployability in compact underwater acoustic systems.

## 1. 核心问题与研究背景

- **应用场景**：自主被动声学平台（滑翔机、剖面浮标等）在功耗、算力、通信上受到严格约束，需要在嵌入式端完成水下目标分类，因此紧凑模型（compact model）成为理想选择。
- **核心矛盾**：
  - 一方面，水下声学数据集（如 ShipsEar）上已出现接近天花板（98%–99%）的分类性能；
  - 另一方面，这类高性能可能源自**评估协议的缺陷**——处理后的 ShipsEar 数据丢失了源录音标识，无法保证同一录音的片段被限制在训练/验证/测试中的单一划分内，导致"录音泄漏"，性能被高估。
- **研究转向**：论文不追求更大模型，而是主张通过**表示感知的特征/模型设计 + 严格的录音级评估**来提升真实可部署性，并以 DeepShip（录音可识别）作为主要验证平台。
- **整体含义**：论文的核心主张是——在紧凑水下声学系统中，**评估协议与声学表示设计的重要性不亚于模型容量**。

## 2. 方法论

### 2.1 核心思想
以"多表示特征工程 + 时间统计池化 + 紧凑卷积架构"为主线，在极低参数量下最大化判别力，同时用录音级划分检验真实泛化能力。

### 2.2 声学表示（多表示对比）
- **常规表示**：STFT、Mel 谱、MFCC、CQT。
- **听觉启发表示**：Gammatone 滤波器组、CARFAC（耳蜗模型），其中 CARFAC 取三种输出：
  - BM（基底膜响应）、IHC（内毛细胞响应）、LI（侧抑制输出）。
- 目的：考察听觉启发表示是否能在**不增加模型复杂度**的前提下提升分类性能。

### 2.3 时间统计池化（关键轻量化技术）
- 对每个时频表示，沿时间维度计算每个频率/滤波通道的**均值与标准差**，拼接为固定长度特征向量。
- 例：128 维 STFT → 256 维（128 均值 + 128 标准差）。
- 同一策略也用于 CNN 学习到的特征图，在分类前做统计池化。
- **消融验证（表 1，ShipsEar STFT）**：
  - RBF-SVM：无池化输入维度 60,800 → F1 0.9641；均值+标准差池化 256 维 → F1 0.9883（维度下降约 237 倍，性能反升）。
  - 2 层 CNN：无池化 302,080 维、1.668M 参数 → F1 0.8987；池化后 5,120 维、183K 参数 → F1 0.9698。

### 2.4 模型设计
- **紧凑 CNN（TinyVGG 风格，4 层）**：通道 32/32/64/64，卷积核 5×15、9×9、3×3、3×3；第 2、第 4 个卷积阶段后接 2×2 最大池化；分类前做统计池化。
- **经典分类器**：Logistic Regression 与 RBF-SVM（基于统计池化特征）。
- **浅层 Patch Transformer**：将 2D 表示切分为局部 patch，投影为 token 后经轻量 Transformer 编码，作为非卷积对比。
- **高容量参照**：标准 ResNet18（11.17M 参数），与约 157K 参数的紧凑 DeepShip CNN 对比。
- **训练配置**：AdamW + 类别加权交叉熵；以验证集宏 F1 做模型选择与早停；测试集仅用于最终评估。

### 2.5 可解释性
- 对 DeepShip STFT 4 层 CNN 的最后一层卷积应用 **Grad-CAM**，仅取正确预测样本，按类别聚合时间与样本，得到类别级频率相关性曲线。

## 6. 主要结论与发现

- **ShipsEar（诊断基准）**：2 层 STFT CNN 达 0.9910 准确率 / 0.9918 宏 F1（183,237 参数）；池化 STFT RBF-SVM 达 0.9888 / 0.9883。但**源录音出处不可恢复，不能解释为录音独立泛化**。作为对照，Yan 等在明确分离录音后，ResNet18 仅得 63.96%（其 sequential multi-head 提升至 70.31%）。
- **DeepShip（录音级评估，主要结论）**：
  - 紧凑 4 层 CNN 测试宏 F1 在 0.6336–0.7226 之间；Mel 取得最高观测测试值 0.7226（但 BM 的验证宏 F1 最高，为 0.6766，故未事后以测试集反选表示）。
  - **表示选择显著影响录音级性能**，且无需更大分类器。
- **模型容量无效**：11.17M 参数 ResNet18 在匹配 5 秒协议下最佳验证宏 F1 仅 0.6110，低于约 157K 参数 Mel CNN 的 0.6519——**参数量增加约 71 倍未带来验证提升**。
- **泛化差距具有跨折一致性**：5 折分组交叉验证中 Mel RBF-SVM 片段级验证宏 F1 为 0.6200 ± 0.0217，录音级聚合后 0.6974 ± 0.0309，平均训练–验证差距 0.3196，说明泛化困难不是单一划分造成的。
- **复现发现**：Chen 等协议下训练准确率升至 99.47%，而留出准确率仅 62.13%（宏 F1 0.6192），远低于原文报告的 95.13%。
- **可解释性**：Grad-CAM 显示类别相关频率关注差异——Passenger 集中于极低频，Tug 偏中低频，Tanker 分布较宽，Cargo 较稀疏，说明 STFT 表示保留了类别相关结构。
- **总体结论**：应优先关注**声学表示与评估设计**，而非单纯增大分类器容量；统计池化使小模型也能利用这些信息。

## 7. 优点

- **评估方法论的批判性反思**：主动识别 ShipsEar 的录音来源泄漏风险，并据此转向 DeepShip 录音级划分，方法论上具有示范意义。
- **严格的划分纪律**：DeepShip 在分段前完成录音级划分，保证训练/验证/测试无源录音重叠；并用 5 折分组交叉验证验证结论稳健性。
- **表示与容量解耦的清晰对照**：通过多表示 × 多模型矩阵，将性能变化归因到表示而非容量。
- **轻量化手段有实证支撑**：统计池化在 RBF-SVM 与 CNN 上均同时降低维度并提升性能（表 1），是一个可复用的设计要点。
- **高容量模型的"负结果"有价值**：ResNet18 在匹配协议下无提升，直接支撑"容量非瓶颈"的论点
